## 2. 约束不是一张“默认参数表”

插件至少需要区分五种约束：原理图电气约束、芯片/接口约束、机械约束、制造能力、项目推荐值。每一条记录应包含 `id`、对象（网络/器件/区域/层）、数值或判定条件、单位、适用工艺、来源及位置、严重程度、测量方法、当前状态。未知写 `unknown`，不能用 0、空字符串或默认值冒充已确认。

制造能力以用户实际选定的厂商、板厚、铜厚、表面处理、层数和服务档位为条件。R01 的同一页面会因铜厚、单双层/多层等条件列出不同最小线宽间距；必须保留这些条件。R01 的制造极限、R08 的布线经验及插件自行提出的保守推荐值是三类信息，不能合并成“嘉立创要求”。

**已核验但不得直接当作全局默认的例子：** R01 抓取版对多层 1 oz 给出 0.09/0.09 mm 最小线宽/线距；过孔部分写有 preferred minimum via hole 0.2 mm；PTH 焊环另有推荐值和极限。PTH 插件焊盘焊环与过孔结构应分别建模，不能把一类要求无差别套给另一类。网站对 mil/mm 有取整显示，内部运算统一用 mm，严格换算 `1 mil = 0.0254 mm`。这些仅证明来源包含的能力边界，最终仍以订板确认值为准。[R01]

## 3. 四层叠层、参考平面与回流

### 3.1 第一阶段的候选方案

**方案 A：L1 信号/器件，L2 完整 GND，L3 完整 GND，L4 信号/器件；电源在外层走线或局部铜区分配。** 这是本项目针对一般 MCU 控制板可优先评估的工程方案，不是所有电路的通用答案。它让 L1、L4 各自有邻近地参考；需要核算电源走线压降、载流、空间、去耦连接和地铜是否被切断。若供电复杂或布线密度高，不能只为保留此方案而勉强压缩电源路径。

**方案 B：L1 信号，L2 GND，L3 电源，L4 信号。** 它能提供电源分配，但 L4 邻近参考往往是 L3；多电源切分、铜区边界和反焊盘可能破坏 L4 关键网络的回流。不能只检查“存在一层 GND”就通过。关键线尽量留在有完整地参考的层；确需变换参考时，应逐一审查返回路径和电源/地之间的交流耦合条件。两个同名网络的几何距离近，也不能替代实际电连接。

R02 列出的 `JLC04161H-3313`、`JLC04161H-1080` 等说明，同为四层板也有不同介质、厚度及铜厚。应先确认实际订单叠层，再确定层分配和阻抗几何。网页默认显示值不能充当用户订单。插件输出应保存所选叠层标识、日期、各介质厚度、铜厚、材料/介电参数和阻焊参数。[R02；R08 pp. 9–12]

### 3.2 必须检查的几何事实

1. 给每段关键走线标注所在层、主要参考层和返回网络；不要只给整个网络一个“参考 GND”标签。
2. 检查投影下方的平面是否连续：槽、分割、板框、密集过孔反焊盘、细颈、孤岛都可能使回流绕行。[R05 Figure 16；R08 pp. 9、12、16]
3. 从 L1 换到 L4 时，即使 L2/L3 都叫 GND，也需确认附近有连接两地层的实际地过孔；同网络名不保证局部低电感路径。R08 p. 15 建议在信号过孔附近放地过孔以减小回路。具体位置还受差分耦合、间距、板层及过孔结构约束，不能编造一个适用于全部板子的固定距离。
4. 外层铺地铜应检查连通性及孤岛；它不能自动替代完整内层参考平面。大片铜面积不等于连续有效的高频回流路径。[R04；R08 pp. 10–12]
5. 不允许仅按 AGND/DGND 命名自动切地。先核查目标芯片的电流路径和数据手册，通常优先靠功能布局分区减少干扰。R07 对单板评估板、多板、不同数字电流规模有不同讨论，不支持一个固定的“ADC 下单点连接”模板。[R07 pp. 7–14]

六层扩展也应先分配各信号层的完整参考，再考虑电源层耦合和可布性。`SIG/GND/SIG/PWR/GND/SIG` 只能作为待评估的层分配示例，必须结合实际介质间距审查，不能仅凭层名判定优劣。[R02；R08 pp. 9–10]

## 4. 从原理图到 MCU 板布局的执行顺序

以下顺序是项目综合，不是对原厂单一流程的逐字转录。

1. **抽取电气事实。** 保存器件 UUID/参考编号、引脚到网络、封装引脚映射、未连接引脚声明、供电树、接口速率/电平。原理图图片只能辅助识别；不能从 OCR 猜测网络并直接铺线。原理图网络表与 PCB 引脚网络应逐项比对。
2. **确认输入条件。** 板框、安装孔、连接器出线方向、高度、壳体禁布、供电范围/电流、器件型号和封装、四层叠层、是否嘉立创贴装。没有真实机械数据的布局标为暂定。
3. **先机械，再功能块。** 锁定板框、安装孔、固定连接器，分出电源入口/保护、稳压、MCU、时钟、模拟采样、通信、调试。按电流/信号流向组织，避免数字/开关电流穿越敏感模拟区域。[R04；R08 pp. 9–12]
4. **处理强约束器件组。** MCU 各电源脚去耦、晶体及负载电容、复位/启动、电源反馈与补偿、接口终端和 ESD 位置。每组约束由具体数据手册或参考板给出。未读取目标器件资料前，不写死晶振最大走线长度、去耦数量或 USB 阻抗值。
5. **布电源和关键网。** 先把输入/开关电源局部回路、敏感模拟、时钟/差分及有时序约束的网络做到可审查，再布普通 GPIO。对有回流约束的线，线与参考层一起审查。[R05；R06；R08]
6. **铺铜后重新验证。** 重新填充铜区，检查地连通、细颈、热焊盘、反焊盘、孤立铜和飞线；布线前的 DRC 结果不能代表铺铜后结果。
7. **导出制造资料并回看。** 在最终版上导出 Gerber、钻孔、BOM、CPL、叠层/工艺说明。重新载入 CAM 或制造检查工具，比较层、板框和坐标，确认数据来自同一版本。[R01–R03]

## 5. 电源完整性与去耦

R06 的重点是局部高频电流回路和连接寄生。评价“去耦靠近 MCU”时，应看电源脚—电容—地返回的完整回路，不能只看器件中心间距。电容电源端、地端与过孔的拓扑会影响有效电感；细长引线和共享地细颈会降低去耦效果。[R06 pp. 6–7；R08 pp. 13–14]

从芯片电压容差、直流误差、允许纹波/瞬态预算与负载变化，制定 PDN 目标；`允许瞬态电压变化 / 负载电流阶跃` 可用作目标阻抗的初步工程估算，但这不是完成了频域 PDN 仿真。MLCC 应考虑直流偏置、容差、温度、封装、ESL/ESR 和自谐振；不能按标称容量机械叠加。不同电容与磁珠/电感可能形成谐振，R06 p. 7 明确讨论阻抗峰值；不能默认“再加一种电容”一定更好。

开关电源应从目标器件数据手册/评估板提取高 di/dt 回路、输入去耦、SW 节点、反馈和补偿禁布条件。R05 能支持“回路/参考平面中断会增加噪声”的机理，但不能替代目标稳压器布局和热参数。电源走线宽度需输入铜厚、电流、温升和允许压降；不要用制造最小宽度决定载流能力。

## 6. 差分、阻抗、时序和串扰

- **先确认接口。** USB、CAN、RS-485、以太网、LVDS 等具有不同速率、终端、共模和保护条件；网络名包含 `_P/_N` 只是候选识别，不能自动套同一阻抗。
- **阻抗是结构属性。** 存储目标单端/差分阻抗及容差、信号层、参考层、介质/铜厚、线宽、对内间距、阻焊模型和所用计算器输入/输出。R02 提供制造商参数和计算入口；本轮未实际计算任何目标板线宽。
- **等长是时延预算。** 根据协议/器件给定偏斜预算及过孔、连接器和实际传播结构分配容差。不要把“完全等长”或长蛇形当成目标；也不能把差分场抵消的理想模型当成不需要参考平面。[R08 pp. 8、14–18]
- **串扰审查需记录并行长度和参考间距。** R08 的 2W/3W 是经验建议，应记录适用上下文；它不能证明眼图或抗扰度达标。必要时增大间距、减少平行长度、调整参考结构或做 SI 分析。
- **过孔须检查返回路径、参考变化及残桩。** 普通 MCU 板不因教程提到盲/埋孔就自动升级制造工艺；先按实际边沿、速率和时延判断是否需要。未经验证不承诺高速总线通过。[R08 pp. 15–17]

## 7. DFM、DFA、热与交付检查

制造检查至少包含：线宽/线距按铜厚及网络类别；铜到板边/开槽；钻孔孔径、成品孔公差、孔铜、孔间距、孔到铜；过孔/插件焊盘焊环分别建模；阻焊开窗与桥；丝印压焊盘、字号和方向；板框闭合且无重复；PTH/NPTH 与铣槽属性正确；所有尺寸单位一致。[R01]

装配检查单独包含：器件库引脚号、焊盘与数据手册 land pattern 一致；1 脚、极性、二极管/LED/电容方向；BOM 与 CPL 的参考编号、数量、器件面、角度和坐标；面向板外的接口；是否需工艺边/基准点；对应 Economic 或 Standard 服务能力。R03 明确有服务档位差异，不能把一列能力搬给另一列。

热设计必须补齐目标 MCU、稳压器、功率器件的数据手册及封装应用说明。需要检查裸露焊盘网络、铜连接、热过孔工艺、阻焊/钢网开窗和焊料流失风险；这些规则不能从外观相似封装推断。现有来源不足以给出特定器件的热过孔阵列、钢网开口比例或允许结温；这些参数保留 `unknown`，等待具体芯片与热条件。没有热仿真/测温，不写“散热已通过”。

高压绝缘爬电/电气间隙也不能等同普通 PCB 最小线距。第一阶段范围为低压 MCU 控制板；出现市电、隔离、高能量回路时需单独收集适用标准、环境和器件隔离资料，不能沿用普通 GPIO 的规则。

## 8. 插件应产出的可验收证据

| 验收项 | 通过所需证据 | 不足时状态 |
|---|---|---|
| 原理图与 PCB 网络一致 | 同一版本的引脚—网络清单、差异报告、未连接声明 | blocked / unknown |
| 封装和极性 | 数据手册封装与引脚映射、库版本、方向审查记录 | needs-review |
| 叠层/阻抗 | 用户选定叠层、制造商参数、计算输入/输出、容差 | unknown |
| 关键网回流 | 各关键段的层/参考、跨槽和换层检查记录 | needs-review |
| 制造几何 | 最终铜区填充后的原生 DRC 报告、工艺规则版本 | failed / unknown |
| 未布线与短路 | 原生工具报告及网络比对，而非肉眼看不到飞线 | failed / unknown |
| 装配资料 | BOM/CPL 对照、坐标/角度/器件面审查 | needs-review |
| 制造数据 | Gerber/钻孔/CAM 检查、同一项目版本或哈希 | needs-review |
| SI / PI / 热 / EMI | 实际运行的仿真或实测方法、输入、结果、适用范围 | not-run |

“DRC 通过”仅表示所配置规则和工具执行所覆盖的项目通过，不能扩展为“功能正常”“阻抗已验收”“EMC 达标”或“可直接量产”。缺少报告与失败应分开，不能把未执行计为 0 错误。

## 9. 首块四层 MCU 板仍需要的资料

确定的范围是嘉立创 EDA 专业版、四层 MCU 控制板。下一轮需要实际项目文件/结构化网络表、MCU 和电源完整型号、板框/孔位/接口约束、供电范围及电流、接口与速率、贴装服务和所选制造叠层。只需要用户提供其实际项目输入，公开手册应由插件继续按型号检索并建立来源记录。

学习闭环应使用每次设计的规则来源、EDA 版本、布局动作、DRC 前后报告、修改原因和打样结果；审阅过的案例才能用于调整流程。此资料库支持持久检索与设计决策，不构成模型权重训练，也不能据此宣称已经获得独立完成任意多层 PCB 的能力。


## 10. USB/ESD 与器件适用条件

R09 为 ST AN4879 Rev 13（October 2026）。其 USB profile 包含准确 MCU/PHY、封装、FS/HS、host/device/OTG、总线或自供电等条件。先识别 profile，再选择供电、保护、VBUS 检测、匹配和上拉；不同器件或封装不能共用固定参考电路。专项执行方法见 [USB 与 ESD](../../wiki/concepts/usb-and-esd.md)。

- **接口保护**：p.10 §2.3 要求专用 ESD 组件尽可能靠近插座。可转为有来源的放置偏好，但没有固定最大距离；元件中心靠近不证明钳位、地返回或系统测试通过。pp.8–10 的 HBM 元件耐受与 IEC 61000-4-2 系统保护分别保存证据。
- **专用 USB 电源**：p.11 §2.5 的 100 nF 陶瓷加 1 μF 钽/陶瓷去耦限定于该文档适用器件的 `VDDUSB`。型号/封装不一定具备此引脚。独立 `VDDUSB` 的后上电、先移除顺序也有特定情境，不是所有 MCU 的默认供电规则。
- **VBUS 与端口角色**：p.11 §2.6 分自供电/总线供电，并解释特定 STM32 sensing 引脚在 MCU 未供电时接 VBUS 的额定风险。检查掉电输入、分压/限压、上拉域与实际逻辑门槛；不能照搬具体引脚和数值。p.16 downstream/host 还需对应的 VBUS 开关和过流上报，不能把 device-only 端口按 host 接法生成。
- **驱动与 PCB 阻抗分开**：p.22 的内部 USB PHY matching 和外部串阻建议只针对其准确器件实现；驱动器输出阻抗不是 PCB 差分阻抗。上拉是否内置也需查型号。枚举成功、没有软件错误或功能能运行，不证明 USB 电气合规。
- **版本边界**：p.25 修订表显示 Rev 3 在 2018 年删除旧版 PCB 走线阻抗/布线章节，当前 Rev 13 不能为早期转载的通用线宽背书。时钟问答还要区分具体型号的 HSI、HSI48/CRS 与 PHY，不能生成所有 STM32 必须外晶振或任意内部 RC 都可用的规则。

R09 不提供本项目可直接复用的通用 TVS 距离、地过孔距离、机壳返回、走线宽度或眼图通过证据。这些需保护器件手册、具体接口/产品规范、实际叠层与分析/测试补齐。

## 11. 阻抗模型、参考平面与四层取舍

R10 为 ADI MT-094 Rev 0（January 2009）。p.1 用最快实际边沿与单程传播延时提示传输线分析的必要性；这是筛查启发，不是自动加终端的决定，也不是按名义时钟划分高低速。教材长度/边沿经验比或线宽示例不作为新板硬阈值。

p.2 把地或电源作参考的前提写成大面积、低阻抗并处于交流零电位。这与 R08 的连续参考/回流要求相容：电源网络名不能证明局部交流返回充分，更不能允许跨平面分割、忽略细颈或跨参考路径。pp.4–5 的对称带状线描述依赖上下参考面与等距几何，不覆盖任意内层结构。

pp.2–5 明确阻抗闭式公式是近似，准确度随几何、目标阻抗和模型变化；计算记录应包含结构、输入、单位、模型版本和适用范围，接受进一步分析/测试/板厂确认。不能把文本提取中的公式自动写成求解程序或生产验收器。

p.6 的外层和内嵌信号比较涵盖屏蔽/辐射、测量调试和去耦的取舍，不证明一个固定四层层序适用于所有 MCU。R10 与现有 R06 去耦机理共同支持按完整电流回路选择布局，而不是追求更多内嵌线或仅优化线长。当前没有目标板阻抗、SI/PI、EMI 或 DRC 通过结论。
