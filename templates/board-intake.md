# 4 层 MCU 控制板输入表

把原理图、专业版工程与手册放在本项目约定的板级工作目录中；私有文件可放 `local/`（默认不提交）。公开案例另行确认许可证。未确认项写“待确认”，不要猜默认值。

| 项目 | 需要的内容 | 为什么必须知道 |
|---|---|---|
| EDA 环境 | 专业版版本、桌面/网页、扩展环境、目标工程/文档标识 | 决定 API 与文件互通能力 |
| 输入工程 | 原理图源文件、网表/等价连接导出、当前 PCB、BOM | 建立唯一的连接依据 |
| MCU | 完整型号、封装、数据手册版本、参考设计 | 检查引脚、供电、去耦、时钟、启动配置 |
| 供电 | 输入范围、各电源电压/峰值/持续电流、保护、时序 | 决定电源回路、铜/过孔、热与压降 |
| 机械 | 板框、尺寸、安装孔、禁布区、接口位置与高度 | 限定可制造和可装配空间 |
| 叠层 | 工厂确认的 4 层结构、层厚/介电、铜厚、板厚 | 决定参考面、阻抗和过孔结构 |
| 接口 | USB/CAN/UART/SPI/I²C/其他、速率、外部线缆、ESD | 决定终端、匹配、回流和保护要求 |
| 敏感电路 | ADC/基准/晶振/RF/开关电源、关键频率/边沿 | 先提取厂商专项规则，再做分区 |
| 封装 | 每个位号的引脚→焊盘映射、尺寸与极性、替代料 | 防止原理图正确而实物接错 |
| 工艺 | 嘉立创具体工艺、最小能力、推荐裕量、装配方式 | 固化 DRC/DFM，而非照抄网页最小值 |
| 验收 | 功能、接口、电源纹波/温升、测试点与测试方法 | 决定板子“能用”的实际证据 |

收到工程后的输出：约束表、未解决问题、器件/网络清单、关键网络分组、布局依据、变更计划；输入不全时继续可独立完成的检查，并标注受影响的步骤。
