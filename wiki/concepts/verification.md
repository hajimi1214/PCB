# 验证与制造：分别保存证据

本页综合 [制造和装配资料](../../research/rules/findings.md)、[专业版接口研究](../../research/eda/findings.md) 和项目验收约定。当前只完成资料/工具检查，没有真实 PCB 的验收报告。

## 不同检查证明不同事情

| 检查 | 能证明的范围 | 仍需其他证据的部分 |
|---|---|---|
| ERC | 所配置电气规则覆盖的原理图问题 | 元件选型、封装、PCB 实际连接与功能 |
| 引脚/网络映射比对 | 原理图与 PCB 的连接模型是否一致 | 几何、制造与电气性能 |
| DRC | 当前版本、当前规则、实际执行项的结果 | 漏配规则、阻抗、SI/PI、热、EMC 和实测功能 |
| 未布线/短路检查 | 原生ratline读取未布连接；本项目主控板native ratline=0，且在线/归档网表的器件/pad/net多重集相符，支持“EDA判定全板连接已布通” | ratline不是短路/间距规则DRC、阻抗、回流质量或接口性能检查 |
| DFM/DFA | 所选工艺和装配条件下的几何/交付检查 | 电气设计与所有生产良率问题 |
| SI/PI/热分析 | 记录的模型与边界条件内的分析 | 未覆盖环境与实际硬件偏差 |
| 样板测试 | 实际测试样本及条件下的行为 | 未测环境、寿命与量产一致性 |

## 原生 DRC 必须重新执行

保存检查开始/结束时间、EDA/扩展版本、目标文档、规则版本、铜区状态、执行项、结果状态与违规清单。读取“最近一次结果”不等于执行检查；异步结果必须等到有效终态。`notChecked`、`checking`、`incomplete`、缺失或陈旧结果均不能映射成“零错误/通过”。精确 API 与最低版本按来源核实，运行时再次探测。

确认错误条数与清单完整性，不把未执行项记为通过。自动任务完成后，对同一份最终工程重跑检查。例外须记原因、范围和审查依据，不用全局关闭规则来消除错误。

## 几何与工艺核对

按实际铜厚/层数/工艺检查线宽线距、铜到边/槽、钻孔/成品孔、孔间距、焊环、阻焊桥、丝印压盘、PTH/NPTH、机械板框和单位。工厂极限、推荐裕量与项目要求分别存储，不能混用。

封装单独核查引脚号、极性和 land pattern。SMT 的 BOM/CPL 应核对位号集合、数量、器件面、角度、原点与坐标；软件原点、元件局部原点和工厂角度约定需要验证。器件面变化后不能只改视觉旋转。

## 制造交付包

从同一最终版本导出 Gerber、钻孔、必要的 BOM/CPL、叠层/工艺说明和源工程。使用独立 CAM/工厂检查查看输出层、板框、孔与对位，确认文件非空且版本一致。记录 EDA 叠层与工厂订单叠层的对应，检查翻转/镜像和单位。不能只检查“生成了 zip 文件”。

## 首板闭环

按功能需求验证供电/纹波/温升、启动/下载、时钟、通信与保护。把测量条件、失败现象、原因和修改回写到案例；每个工程结论有实测或分析边界。项目工具 `verify-sources` 和单元测试仅验证知识存档及辅助代码，不能作为上述任一板级通过证据。
