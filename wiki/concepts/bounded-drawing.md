# 有限 PCB 写入与案例迁移

本页把本轮实际读取的 6 页嘉立创官方 API 和 ADI MT-100 Rev0 转成插件的执行规则；来源与短引文可查[EDA来源记录](../../research/eda/sources.json)和[制造/器件来源记录](../../research/rules/sources.json)。具体工具流程见[有限布局和布线](../../docs/drawing.md)。

## 从 API 得到的写入约束

`eda-component-modify` 的示例明确要求 `modify` 后重新 `get`。因此平移元件时检查新位置、同一层/角度、位号以及每个物理焊盘的刚性平移、网络和编号，不能只读旧返回对象。物理焊盘号重复不能去重；暂不引入旋转/翻面，以免未经验证的坐标变换破坏焊盘位置。

`eda-group-commit` 与 `eda-group-rollback` 说明提交/回滚都返回 boolean；回滚只覆盖未提交组。本项目额外读取源码核对恢复结果。API故障、外部焦点改变或回滚返回false时，保留失败和恢复依据，不把一个“调用已发出”当成事务成功。

`eda-document-source` 允许读取当前文档源码，undefined表示未打开/失败。以此保存源码基线、哈希和写后证据；相同UUID不保证内容未变，预览后有变更必须重做计划。源码读取与写API没有原子锁，不能保证外部并发编辑不会进入同一个命令组。

`eda-project-import` 的 `Offline Client Local Path` 只适用于离线环境，且同名不覆盖。`.epro2`归档与原生工程索引不是一种文件。原生 `.eprj3` 有支持文件，建立副本必须复制整个项目目录；不能只复制索引后让编辑器仍引用原项目几何。

`eda-netlist-export` 的文件结果可为undefined。可下载/可导出只说明取得文件，不说明原理图与PCB等价；几何写入后必须重新核对连接，完整原生DRC与物理性能测试仍见[验证与制造](verification.md)。

## 从 ADI 原型教程得到的迁移规则

[MT-100: Breadboarding and Prototyping Techniques](https://www.analog.com/media/en/training-seminars/tutorials/MT-100.pdf)，Rev0 January 2009，是原型方法教程，不是现行板厂工艺表。本轮取得完整1086799字节PDF并解析15页；首次截断版本不作为证据。

- PDF p.10：用双层板配飞线模拟多层连接时，飞线阻抗难控制，高频性能可能明显不同。把一个参考设计转换为四层板时，重新建立层/参考面和路径约束，不只搬元件坐标。
- PDF p.10：使用最终封装做原型，封装/转接板寄生会改变带宽和建立时间。换封装必须重新检查物理焊盘、去耦回路和接口模型，即使网络名相同也不能直接复用原布局的验收结论。
- PDF pp.11–12：AD8001评估板给出去耦紧邻供电脚、低寄生回路、地平面过孔连接的实例。1000 pF、0.01 μF、10 μF、电路50 Ω线和器件周围特定挖空属于此器件/评估电路；不能转为MCU统一参数或一般切地规则。
- PDF pp.12–14：原厂评估板的原理图、BOM和各层布局应联合学习。参考来源可用于提出候选规则，仍需匹配目标器件/封装/叠层及实际测量。公开可下载的CAD并不自动授予插件重分发权利。

PDF p.6 的25 mil线宽、12 mil间距是在旧式铣制原型板语境内；本项目不会把这些数字用于嘉立创现行制造约束。PDF p.1也指出宏模型通常没有充分包括封装/PCB寄生，仿真不能代替相应样板测量。

## 首个可检验的执行范围

只在保存过的原生工程副本进行小批量元件平移、已有网络导线和通孔创建。带来源的线宽、钻孔、焊环和本批区域用于检查显式参数；未知机械边界、障碍、回流、阻抗、供电载流和原理图等价都保留为待验证项。

## 嘉立创自动布线作业

嘉立创 `PCB_Document.startAutoRouting` 从 EDA 4.1.79 起返回长作业句柄。`RoutingNets` 缺省或为空会拓展到所有未布网络，`layers` 应只给启用铜层，已有导线/过孔默认保留。插件要求显式的1–64个已有网络和1–8个实际启用SIGNAL层，固定45度、保留几何、布通率优先，并在原生副本里执行。

轮询 `getAutoJobStatus`，再用 `getAutoJobLog` 读取进度，终态再完整分页 `getRatlines`。插件会记录源码摘要、partial标志与未布飞线数。作业完成/零飞线不等于完整DRC、网络拓扑等价、SI/PI或制造验收。取消是异步请求，必须继续轮询。若启动回执丢失，保留一次性attempt记录，人工核对副本中的当前job/几何后才能新建计划。

官方 `autoRouting()` 同步接口有900秒内部上限，MCP/CLI等待时间无法覆盖。作业API适合可查询和取消的长作业。完整参数与实测边界见[绘板流程](../../docs/drawing.md)。
