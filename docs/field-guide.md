# Codex PCB 设计指南：多功能 MCU 开发板

本文面向 Codex PCB 技能的作者，说明如何把硬件工程读取成有来源、可审查的布局与布线计划。它不是某一器件手册或某一块板子的设计模板。电气与制造规则按来源、版本、适用条件和验证方式保存，具体依据见[多层板与制造规则](../research/rules/findings.md)、[开源硬件案例](../research/cases/findings.md)、[原理图到 PCB](../wiki/concepts/schematic-to-pcb.md)、[叠层与回流](../wiki/concepts/stackup-and-return.md)和[验证流程](../wiki/concepts/verification.md)。

## 证据边界

每项知识必须区分：

- **原始观测**：结构化工程、制造商资料、器件手册或用户明确提供的要求。保留文档/对象标识、版本和定位信息。
- **工程方法**：可用于规划和审查的一般做法，需要按器件、接口和制造条件确认。
- **待确认**：输入不足或证据冲突时为 `unknown` / `needs-review`，不从惯例、网络名或图像外观补猜。

工程字段存在不代表功能已验证；原理图图片和网页示意不能代替电气连接真值。原生 DRC 也不能代替 SI/PI、机械、制造及样板测试。

## 先建立电路与机械模型

在布局前读取并绑定以下内容：

1. 工程、Board、原理图页及 PCB 文档的稳定 ID、版本、单位和层定义。先确认当前目标文档，防止修改到同一工程中的另一块板。
2. 器件 UUID、位号、准确器件型号、符号 pin、物理焊盘集合、封装、方向、层别、供货/替代料。重复编号的多个实际焊盘、散热焊盘、机械孔和无网焊盘均保留，不能按编号去重。
3. 逐引脚网络、未连接声明、供电域、接口、网类与差分对成员。由真实连接关系识别电气组，不用页面相邻、名称相似或 OCR 推断 pin-net。
4. 板框、孔位、禁布/禁铜区、连接器出线方向、线缆弯折、器件高度/壳体、按键触达、声孔/光路和测试可达性。缺少结构模型或尺寸时把布局标为暂定。
5. 实际订单叠层、铜厚、材料、工艺能力、装配服务、各电源范围/电流、负载瞬态、接口速率/边沿、环境与验收测试。每项记录单位及来源。

同一工程含多板时，为每个 Board 单独维护元件/网络/层关系，并显式描述板对板连接。不能把子板的层数、位号或网络混进主板。

## 功能分区作为候选布局，而非电气事实

复杂 MCU 控制板通常可按以下类别提出分区建议：MCU/启动/时钟/调试、输入供电与保护、电池/充电、稳压与负载开关、USB 数据与 USB-UART、存储、显示/触控、传感器、音频、驱动/电机、指示灯、用户接口和机械固定件。

这些类别只用作检索与布局候选。电机、扬声器、磁场/惯性传感器、开关节点和麦克风之间的冲突，应先根据器件型号、测量目标和实际电流路径建立审查项；没有源数据时不能套入统一距离。接口靠边、同组元件靠近、测试点可探测等是受机械与电气硬约束约束的软偏好。

## 层叠与参考层

四层铜板比较叠层时，结合供电分配、信号密度、参考连续性和实际介质/铜厚，不从固定层名推断功能。每个启用铜层要与未启用预置层区分；还需识别器件层、机械层、负片内电层等不同语义。

为每段关键网络保存所在层、参考层/网络、线段、过孔和铜区状态。检查参考投影下方的平面分割、槽、板边、细颈、密集反焊盘和孤岛。信号跨层时核查返回电流的转换路径；两个平面名字相同不代表在局部已经连通。模拟与数字回流依具体器件与电流路径判断，不按网络名自动分割地。

EDA 中保存的物理层叠、阻抗计算输入和实际制造订单是不同对象。只有获得真实工厂层叠材料/厚度/铜厚/阻焊参数后，才能计算受控阻抗；工程中的层名或线宽记录不能证明阻抗合格。参见 [JLCPCB、TI 与 ADI 来源及适用条件](../research/rules/findings.md)。

## 关键电路类别的布局约束

- **MCU/模组**：先确认准确封装、pinout、供电脚、启动脚、时钟、下载/复位接口、模块天线及厂商 keepout，再决定扇出和邻接关系。模组资料不能被裸芯片资料替换。
- **USB-C / USB-UART**：把供电路径、接口保护和各类 USB 数据接口独立建模。只有电气资料确认后才将网络配成差分对；检查连续参考、层转换、回流、线宽/间距、终端与时延预算。接口名称或历史线宽不能作为阻抗目标。
- **电池与电源管理**：从原理图和芯片手册建立电源树，逐项核对电池极性、输入保护、充电支路、开关/稳压、反馈采样和负载回路。按峰值/持续电流、铜厚、允许压降和温升评估走线与过孔；制造最小线宽不能代表载流能力。
- **存储和数字显示**：确认真实接口类型、时序和速率。连接器优先满足插拔/线缆和壳体约束；高速时钟/数据与参考面、过孔、偏斜和拓扑一起审查。板对板显示连接逐项匹配两端板的连接器物理焊盘和网络。
- **传感器**：按目标物理量、器件坐标系、光孔/声孔/安装应力和周边干扰安排方向与位置。磁场、振动、光学、热量和模拟输入的隔离依据具体器件手册、结构及测试结果，不能凭器件分类设固定距离。
- **音频和驱动负载**：分开识别低电平输入、偏置/参考、高电流功放与负载返回。检查电源去耦闭环、开关路径、器件散热及真实声学/连接器机械条件。
- **机械/装配**：锁定板框、安装孔和固定接口，再安排器件面、连接器、高度、可达性和工艺边界。BOM/CPL 中位号、数量、方向、器件面、坐标系和工厂角度约定需要独立核查。

## 约束优先级与可回滚布局策略

建议插件按决策硬度分级：

1. **阻止写入的条件**：目标工程/Board 身份、引脚/焊盘/网络映射、封装极性、电气绝对额定、已确认板框/孔/接口位、用户锁定对象。
2. **有来源的器件/接口约束**：供电回路、时钟/启动、USB/存储/显示时序、已计算阻抗、模拟/传感器限制、器件专项禁布和热要求。
3. **制造与装配条件**：选定工厂叠层、铜厚、规则、孔/板边/阻焊能力、器件高度、拼板/装配、BOM/CPL。
4. **待优化偏好**：功能块紧凑、接口靠边、缩短关键回路、减少换层/绕行、保留测试与返修空间。软偏好只有在硬约束满足后才排序。

实际流程应先保存基线，在副本中分批布局：固定机械接口与可信禁布区；再安排电源/保护及 MCU/时钟；处理有接口或回流约束的网络；最后布低速信号并填充铜区。每批变更均在写前检查对象和版本，写后读取坐标、方向、层、pad-net、走线、铜区和未连接状态。无法可靠回滚的操作要通过独立副本恢复。自动布线器只产生候选线路，不代替器件布局、回流审查或 DRC。

每个动作的证据记录至少包含 `objectUUID/reference`、约束 ID、前后状态、单位/坐标/层、理由/来源、置信度、执行结果、验证器状态和恢复点。不能仅凭写 API 成功返回就称为写入完成。

## 可自动化检查与必须保留的人工/工具审查

| 自动检查（前提是结构输入完整） | 仍需专业工具或人工确认 |
|---|---|
| 归档/格式/编辑器版本、Board 和页面关联、启用层数与未知文档类型 | 在目标 Pro 版本成功打开/保存工程，处理版本兼容提示 |
| SCH/PCB 位号与 Device ID 集合差异、缺失/重复项、footprint 关联是否存在 | 逐 pin→pad→net 语义映射、器件规格/封装 land pattern/极性 |
| 网络/层 ID 引用、pad-net 对象归属、单位和范围异常 | 飞线/铜连通、短路、原生 ERC/完整 DRC 与正确规则集合 |
| 已知板框/孔/keepout 与器件外形的几何碰撞 | 壳体、插拔、线缆、人体触达、散热/声光特性与实际装配 |
| 候选差分网络、长度/线宽/换层/参考层连续性统计 | 协议约束、阻抗计算、SI/PI、EMI、眼图/实测和工厂叠层 |
| 铜区过期/孤岛/跨层回流缺口（有可靠几何引擎时） | 铺铜/内电层重建、制造 Gerber/CAM/DFM、样板测试 |

DRC 报告的 `notChecked`、`checking`、`incomplete`、超时、旧版本或缺失均不算“通过”；DRC 仅覆盖实际执行的规则。SI/PI/热/EMI、功能、电池安全及量产结论分别需要对应的仿真/实测证据。

## 可检索知识库字段

将芯片家族规则与单板实例规则分开，避免把某块板的坐标或线宽误当通用知识。

| 记录类型 | 字段建议 |
|---|---|
| `source` | 来源 URL/文档/页面，SHA/版本，获取时间，权威性/许可，证据位置和限制 |
| `family` | 芯片/模组准确型号与修订，pinout/电压/时序/封装，厂商设计手册/参考设计引用，未确认能力 |
| `board` | 工程/Board/PCB/SCH UUID，工具/格式版本，单位/原点、实际 enabled layers、factory stackup、hash |
| `component` | 稳定 UUID、位号、device/symbol/footprint 版本、pin/物理 pad 集、pad-net、器件面/方向/坐标/高度、BOM 替代关系 |
| `net` | UUID、名称、端点 `component/pin/pad`、网类/接口协议、约束、目标/单位/来源、状态 |
| `mechanical_region` | board outline、孔、keepout、边缘接口、装配/高度/光声/天线区，坐标系/来源/硬度 |
| `stackup_layer` | 物理 layer ID、层 type/name/enabled、角色/参考、材料/介质/铜厚、订单栈叠和计算器版本 |
| `constraint` | 稳定 ID、对象、数值/单位或判定方法、hard/soft/优先级、来源、验证器、状态/waiver |
| `placement_route_decision` | 前后状态、对象 ID、原因/约束、单位、层/参考、证据、confidence、写入批次与 rollback ID |
| `verification_run` | 工具/EDA/API 版本、工程 hash、规则 hash、时间、完整性状态、违规/飞线/豁免、DRC/DFM/SI/实测证据 |
| `learning_case` | 输入类别、候选方案、被接受/拒绝理由、观察结果、通用性范围、回归测试与许可 |

`unknown` 必须显式保留。只有获得 datasheet、原生 DRC/连通报告、工厂叠层和测试结果后，才更新对应状态；单一示范工程不能作为所有后续 PCB 的监督真值。
