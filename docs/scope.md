# 项目范围与当前边界

**PCB** 是给 Codex 使用的 PCB 设计助手，目标是在嘉立创 EDA 专业版中，根据用户已有原理图，完成有约束、有检查、有恢复依据的 PCB 设计。第一阶段验证 4 层 MCU 控制板。用户于 2026-11-21 确认该目标。

## 本次交付

- 读取官方文档和开源硬件，保存有哈希的来源快照、事实摘要与局限。
- 建立原理图到 PCB、多层板、制造与验收知识库。
- 提供 repo-local Codex 插件包、技能入口、知识/来源/`.epro2` 检索、固定 EDA 身份/网表/物理焊盘/层/DRC 观察与来源完整性检查。
- 从用户提供的样例产生本机私有结构模型和案例知识，保留逐对象证据；从中提炼公开的通用规划方法。
- 给出专业版扩展的适配方案、输入条件和真实板子的验证路线。

这些是可复用的外部知识与受约束工具。0.3实现本地原生副本的有限平移/导线/通孔写入、预览、恢复记录、原生自动布线job、MCP ratline/netlist验证与归档导出。0.4增加受约束的制造资料导出，导出前重跑DRC并核对零飞线，导出后验证Gerber、钻孔、BOM和CPL结构。JLCEDA Pro 网页版测试副本实测141项DRC、0个问题；Gerber UI报告生成成功，但本地文件落盘与ZIP层结构仍未验收。测试副本原生router job停在1%后取消，当前副本仍待清理。原主控板netlist映射与离线归档一致，ratline=0；原主控板缓存DRC为notChecked。未进行模型预训练或微调；未声称已有可下单的四层MCU成品。流程见[有限绘板](drawing.md)。

## 产品完成条件

收到实际工程后，在指定 EDA/扩展版本中验证：原理图与网表同步、封装焊盘映射、板框/安装孔、叠层与网络规则、分区与关键器件布局、布线/铺铜、网络连通与 DRC、制造交付。每个步骤有输入、输出、证据和恢复方法。

至少保留原理图/PCB 源工程、网表或等价的连接快照、器件封装核对表、叠层和约束、DRC/未布线结果、变更记录，以及独立检查的 Gerber/钻孔文件；有 SMT 时增加 BOM/坐标与方向核对。是否达到电气、信号、电源、热和量产要求，取决于相应审查与实测。

## 第一块验证板

优先选用低压、功能清楚、器件封装易核查的 MCU 控制板。MCU 型号、输入电压/各电源最大电流、板框与接口位置、通信接口、关键频率、工厂叠层和装配方式由真实工程决定，当前不虚构这些条件。若有 USB、RF、开关电源或隔离电路，必须加入对应厂商规则与验证项。

## 可度量验收

| 检查项 | 证据 | 判定方式 |
|---|---|---|
| 网络映射 | 原理图网表、PCB 引脚/焊盘/网络清单 | 无意外增删、短接或漏接；NC 有理由 |
| 封装 | 器件手册、封装尺寸、引脚编号、极性 | 逐器件核对；库名称相同不算证据 |
| EDA 写入 | 写前/写后导出或快照 | 目标正确、差异在预期内、能恢复 |
| 多层约束 | 工厂叠层、网络类别、阻抗计算依据 | 参数明确；关键网络参考连续 |
| 布线 | 未布线清单、DRC 结果、关键网络检查 | 未布线为零或逐项解释；规则错误清零或明确审定 |
| 制造文件 | Gerber、钻孔、机械尺寸、BOM/坐标 | 独立查看输出并与源工程核对 |
| 电路功能 | ERC、专项分析、样板测试记录 | 与设计需求逐条对应，不能从 DRC 推断 |
