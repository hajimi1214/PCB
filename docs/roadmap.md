# 从研究到可用插件

## 0：资料库与只读技能（已完成）

完成：公开资料证据、来源完整性检查、知识索引、通用多层板案例指南、repo-local Codex 插件结构、MCP 搜索/来源/私有案例检索/`.epro2` 结构检查，以及固定 EDA 状态/会话/工程/网表/物理焊盘/层/DRC 观察。用户提供的设计只用于本机私有案例；工程归档与完整模型不会进入 Git 包。该交付建立可复用检索和检查流程，不等于模型权重训练、原理图/PCB网表等价、几何连通或板级验收。

## 1：专业版只读适配

已在嘉立创 EDA 专业版 4.1.100 的独立空 headless 会话中验证官方 CLI 管道输出、doctor、session list 和固定环境 action。下一步是在用户明确提供的测试副本中读取工程身份、原生网表、物理焊盘/层和完整 DRC，再与离线 `.epro2` 结构逐项比较；原工程不作写入。其他版本/环境先走 status 和能力降级，不把函数存在当作成功。

验收：读取得到可复核的位号、焊盘、网络和层表；既有工程无变化。建立 schema 版本和不支持能力的明确错误。

## 2：有限写入与恢复

0.3已实现登记原生副本、源码基线与预览、最多20项元件平移/网络导线/通孔、物理焊盘读取核对、失败回滚、异步原生自动布线、状态/取消、全量剩余飞线读取和归档导出。0.4增加新鲜DRC/零飞线门槛，以及 Gerber/钻孔、BOM、CPL 文件生成和内容校验。JLCEDA Pro 4.1.105 网页 UI 已真实检查测试副本的141项DRC且零问题，Gerber UI报告生成成功；下载保存位置尚未完成，文件、CAM和MCP真实制造导出仍待验收。完整写入→布线→导出→重开尚未完成。自动布局/避障优化、板框生成、层叠/规则写入、翻面/旋转、铺铜仍未实现。见[有限绘板](drawing.md)。

验收：重复读取一致；重复命令不会复制器件或破坏网表；中途异常可停止并恢复测试副本。

## 3：4 层 MCU 基准

先完成 [输入清单](../templates/board-intake.md)。确定叠层和约束，按连接器、供电、MCU、去耦、时钟、敏感模拟/接口的依赖关系布局，优先关键网络，之后处理普通信号和铜皮。每次更改都重新检查连接与规则。

验收：原理图/PCB 网络一致，封装审核完整，未布线与 DRC 结果可追溯；工厂文件经过独立检查。由有经验工程师复核首块样板，实测供电、下载/启动、时钟与接口功能，并将失败写回案例。

## 4：扩展能力

用变更回归验证换 MCU、换封装、改网、改板框、换叠层的行为。6/8 层、射频、高速总线和其他复杂设计分别增加专用规则与样例，未验证的情境在技能中保留边界。

每个阶段使用独立的真实验收证据；README 不提前将规划中的功能标记为已完成。
